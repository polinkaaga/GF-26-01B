# Шаблон СФУ для Typst (СТУ 7.5–07–2021)

## Файлы

```
sfu-typst-template/
├── sfu-template.typ   ← ШАБЛОН (не редактируй без надобности)
└── main.typ           ← ТВОЙ ДОКУМЕНТ (редактируй этот файл)
```

## Быстрый старт в Typst Editor (AppStore)

1. Создай новую папку проекта в приложении
2. Загрузи оба файла в эту папку
3. Открой `main.typ` — он является главным файлом
4. Заполни параметры в `#show: sfu-doc.with(...)` своими данными
5. Пиши документ ниже — шаблон применится автоматически

## Параметры шаблона

| Параметр        | Описание                                    | Пример                        |
|-----------------|---------------------------------------------|-------------------------------|
| `institute`     | Название института (без слова «институт»)   | `"Гуманитарный"`              |
| `department`    | Название кафедры (без слова «кафедра»)      | `"Философии"`                 |
| `doc-type`      | Тип документа прописными                    | `"РЕФЕРАТ"` / `"КУРСОВАЯ РАБОТА"` |
| `discipline`    | Дисциплина                                  | `"Философия"`                 |
| `topic`         | Тема работы                                 | `"Название темы"`             |
| `teacher`       | Преподаватель                               | `"доц., к.ф.н. Иванов И.И."` |
| `student-group` | Группа и номер зачётки                      | `"ГН21-01З № 212101001"`      |
| `student`       | Студент                                     | `"Иванов И.И."`          |
| `year`          | Год                                         | `"2025"`                      |
| `city`          | Город (по умолчанию Красноярск)             | `"Красноярск"`                |

## Вспомогательные функции

```typst
#sfu-section("ВВЕДЕНИЕ")       // структурный заголовок
#sfu-table(number: "1", caption: "Название", [...])  // таблица
#sfu-figure(number: "1", caption: "Название", [...]) // рисунок
#sfu-formula(number: "1", $формула$)                 // формула
#sfu-cite("13")                // ссылка [13]
#sfu-cite("20", page: "102")   // ссылка [20, с. 102]
#sfu-bibliography((            // список источников
  [Автор. Книга. — Город, Год.],
))
```

## Стандарт (основные параметры, реализованные в шаблоне)

- Поля: левое 30 мм, правое 10 мм, верхнее и нижнее 20 мм
- Шрифт: Times New Roman 14 pt
- Межстрочный: полуторный
- Абзацный отступ: 12,5 мм (5 знаков)
- Выравнивание: по ширине
- Нумерация страниц: по центру внизу, арабскими цифрами
- Титульный лист: в нумерацию включён, номер не ставится
